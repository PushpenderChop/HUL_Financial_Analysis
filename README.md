# Hindustan Unilever Ltd. Financial Analysis and Valuation

This repository contains a financial analysis and valuation project on Hindustan Unilever Ltd. (HUL). The project includes historical financial statement analysis, forecasting, ratio analysis, discounted cash flow (DCF) valuation, and comparable company analysis using Excel and a supporting report.

## Project Objective

The objective of this project is to evaluate the financial performance, operating efficiency, cash flow strength, and valuation of Hindustan Unilever Ltd. through a structured financial modeling approach.

## Files Included

- `Financial-Analysis-Report-of-HUL.pdf` – Detailed financial analysis report covering income statement analysis, balance sheet analysis, cash flow analysis, ratio analysis, DCF valuation, and comparable company analysis.
- `Hindustan-Unilever.xlsx` – Excel-based financial model containing historical financial statements, assumptions, forecasts, DCF modelling, and COMP analysis.

## Analysis Covered

- Historical Income Statement Analysis
- Balance Sheet Analysis
- Cash Flow Statement Analysis
- Financial Ratio Analysis
- Revenue and profitability trend analysis
- Forecasting of key financial items
- WACC Calculation
- Discounted Cash Flow (DCF) Valuation
- Comparable Company (COMP) Analysis

## Key Highlights

- Historical revenue analysis from FY17 to FY26 with forward estimates up to FY30.
- Profitability analysis using Gross Profit Margin, EBITDA Margin, EBIT Margin, and Net Profit Margin.
- Balance sheet review covering reserves, borrowings, working capital, and asset structure.
- Cash flow analysis with focus on operating, investing, and financing cash flows.
- DCF valuation using assumptions such as beta, equity risk premium, tax rate, cost of debt, and WACC.
- Comparable valuation using peer metrics such as EV/Revenue, EV/EBITDA, and P/E.
